How the grades work

Source. The league save's trade history (every GM-to-GM trade since the season opened), plus trades posted in Discord after the latest save, numbered D#n. AI trades in the game's other leagues are left out.

Value. The game's own trade valuation of each side at the time of the deal, as the save records it. Value in is what a team received; value out is what it sent. A trade is a Win or a Loss for a team only when the gap is more than of the value moved; inside that band it is Even, a deal both sides' AI GMs would accept. Even trades count as neither a win nor a loss, but their value still counts toward Edge. For Discord-posted trades the save has no recorded value, so picks use the save's pick values and players use the save's player values plus 5%, which is how the game's recorded values ran across recent trades.

Edge. (value in − value out) ÷ (value in + value out): value won as a share of value moved, so a busy GM and a quiet one compare fairly. The grade comes from Edge using the cutoffs below. A team needs at least trades for a grade (fewer shows INC) and for a full grade; in between, the grade carries an asterisk.

Combined trades. The game allows at most 5 assets per side in one trade, so bigger deals get entered as several trades on the same day between the same two teams. Those are combined into one deal here and graded as a whole; their trade number joins the parts, like 3844+3845+3846.

Trade cards. Click any trade, in a team's list or under Every trade, to open its card: each player with position, overall, age and current contract, each pick, and what every asset is worth in the save of . The game stores one value per side at the moment of a trade, not one per asset, so each side's value at the trade sits beside what the same assets are worth now; the gap is how the trade has aged. The recorded values add 5% to the players sent by one side of each trade (the league's trade difficulty, 1.05), so values now add the same 5% to those players to compare like for like. A player who has since left as a free agent or retired counts as 0, a 2027 pick counts as the player drafted with it, and a negative value means the game counts the contract as a cost.

What it measures. Asset value, not whether a trade helped a team win. Cap dumps, rentals and win-now veterans for young talent count as value lost. Where a team took picks to retain salary, that shows as value won, since the game does not price the cap cost. Three-team trades are split per asset by estimate. Players are shown with their overall and age as of the latest save, not at trade time.
